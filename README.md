# MODI

تطبيق أندرويد لتسجيل نقاط ألعاب الورق والدومينو، مبني باستخدام **Expo** و**React Native** و**TypeScript**.

## المزايا

- دعم العربية والإنجليزية والكردية مع دعم اتجاه RTL.
- دعم من لاعبين إلى خمسة لاعبين أو فرق.
- نظاما لعب: الدومينو والورق.
- تحديد هدف الفوز من 100 إلى 9999.
- تعديل أسماء اللاعبين والهدف أثناء الجولة.
- تسجيل نقاط مستقلة لكل لاعب في جولات الورق.
- إظهار علامة ❌ للفائز بالطرقة عند عدم تسجيل نقاط له.
- حذف جولة خاطئة واستعادة آخر جولة محذوفة.
- عرض مجموع كل لاعب، وفارق النقاط بين أعلى وأقل مجموع.
- حفظ الحالة محليًا باستخدام AsyncStorage.
- رابط حساب المطور على Instagram: [@sg_r4](https://www.instagram.com/sg_r4?igsi=MTgyanduZXhnYzB3OA==)

## المتطلبات

- Node.js 22 أو أحدث.
- pnpm 9 أو أحدث.
- Expo SDK 54.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

لتشغيل نسخة الويب فقط:

```bash
pnpm dev:metro
```

## الفحوصات

```bash
pnpm test
pnpm check
pnpm lint
```

## البنية

- `app/(tabs)/index.tsx`: شاشة التسجيل ومنطق اللعبة.
- `lib/score-difference.ts`: حساب فارق النقاط.
- `tests/`: اختبارات Vitest.
- `assets/images/`: أيقونات وشعار التطبيق.
